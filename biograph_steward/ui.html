What do claim, candidate and accepted mean?

Claim: a recorded statement linking entities. Candidate: a local review status, available for inspection. Read the source to see what evidence it reports. Accepted: a local review decision, not clinical validation or a universal truth guarantee.

Graph and decision files
Use the full workspace ZIP above for the saved graph and its source files. In an applied retained-graph example, that ZIP also preserves the existing decisions and original baseline inside source_retained_package. The answer ZIP covers only the selected question.
In an editable local workspace, the button below can prepare a new graph-and-decision package. That new package initially retains every record as undecided. It does not replace an existing applied decision ledger or establish biological acceptance.
How the package relates to this workspace
  • retained_graph.json: the resulting workspace graph. Its nodes are the proteins and other entities; its edges are individual evidence records.
  • edge_dispositions.jsonl: one keep, prune or abstain (undecided) decision per original evidence record.
  • baseline_packet/source/graph.json: the original workspace graph before those decisions. The surrounding source folder preserves its supporting records.
A Pharos annotation and a qualified assay observation can appear as two evidence records for the same protein pair. Only an explicit prune decision removes a record from the retained graph; its original record remains in the source baseline.
