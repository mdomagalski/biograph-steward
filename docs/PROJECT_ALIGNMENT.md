# Current project alignment

Updated November 16, 2026, against the user-supplied organizer brief, proposal and Slack excerpts. This is a functional crosswalk, not organizer approval or an estimated score. The excerpts were not independently retrieved from Slack. Earlier assessments and retired experiments remain in the [archive ledger](EXPERIMENT_HISTORY.md).

BioGraph Steward now delivers a bounded, model-directed **question → plan → source query → focused evidence graph → source inspection → review proposals** workflow. The [current-source agent](SOURCE_AGENT.md) uses the actual native STRING physical, native GO location and qualified archived-pathway tools. Deterministic adapters validate scope and execute the query; the model prioritizes citations and selects source-bound review proposals. It does not silently accept or prune biological claims. This current route is separate from the older construction planner and literature-audit experiments.

## Organizer requirements and judging crosswalk

The original brief permits **autonomous or semi-autonomous software**. Its topic is structured-data integration and link prediction: an agent builds contextualized graphs, then the **same graph-learning method** is applied to baseline and enriched graphs to predict held-out experimentally measured relationships. Our paired learner comparisons are complete; they do not demonstrate consistent incremental benefit. The separate historical protein-function study and current agent query-parity check do not replace that endpoint.

The [scientist-access delivery](evaluations/DEMOCRATIZATION_DELIVERY_20261116.md)
makes the existing graph constructor easier to find, with three steps and a
direct operator form entry. The saved reviewer version explains local use.
Together with the source-query agent, this demonstrates a focused
semi-autonomous workflow and reusable construction, without requiring graph
syntax. Independent usability and external-cohort validation remain separate
ways to extend that evidence.

Candidate/accepted are local workflow states. Abstained records remain retained; the agent's proposals apply no decisions. |
