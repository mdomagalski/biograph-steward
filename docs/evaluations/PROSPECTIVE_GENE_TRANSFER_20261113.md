# Prospective transfer to a fixed new-gene sample

The historical source-qualification and resource-allocation method did **not**
meet the predeclared transfer criterion in this sample. This preserves a useful
negative result: the earlier positive RA concentration result on consumed
reference data does not establish a broadly transferable biological benefit.
No production-pruning policy, graph claim or calibrated accuracy estimate is
changed by this comparison.

## What was fixed before new values

The original coessentiality and RA experiments remain unchanged. The new
workflow reuses their native source projection, exact historical-model
qualification, NetworkX RA, author XSwap, native NPY range decoding,
fractional ties and query-matched backgrounds. A separate ordinary-Gold
adapter supplies the prospective cohort; it does not pretend to have the
earlier learner-packet supervision or relax the old 92-gene checks.

One SRSWOR sample of 128 genes was drawn with seed 2026111302 from a metadata-only
17,231-gene reviewed, uniquely mapped subset of the native reference genes.
Eligibility required one consistent canonical reviewed human UniProt product,
one approved HGNC/Entrez relationship, no conflicting secondary product and
one canonical chromosome. The original 98-gene/HGNC/product identities were
excluded. The twenty extra conservative product-conflict exclusions and all
raw mapping fields are preserved. Inclusion probability is 128/17231; this
does not make the functional endpoint a whole-proteome accuracy estimate.

There were no replacements or Wiki, Pharos, fitness or TDL selection criteria.
All 128 requested Pharos identities and pathway responses were complete and
version-consistent: 1,470 pathway rows, including 585 Wiki rows. Eighty-four
genes had valid complete-zero Wiki responses. Other source families were
explicitly unretrieved, not absent. A required failed, missing, truncated or
inconsistent response would have blocked the entire comparison.

The actual ordinary Gold graph and exact historical native-model packet
defined the source views. The research historical feature view contains
103 source-positive gene/version connections (100 compatible gene-level
xrefs and three exact protein xrefs); 307 connections remain UNKNOWN. Those
omissions are not false biological labels or production-pruning decisions.

All 128 genes remain in each absolute-mean denominator. A zero-context query
adds zero to both observed and expected sums in pooled O/E, so retaining zeros
does not itself make that ratio coverage-adjusted. Effective query/pair
coverage and absolute affinity must accompany it. The 8,128 unordered sampled pairs
include 7,648 nonsyntenic primary pairs and 480 same-chromosome preservation
rows. The source support is sparse; the historical view has only 26 active
queries and 102 zero-context queries. Coverage was documented before new
reference values without selecting a different sample or threshold.

## Fixed endpoint and controls

The primary readout uses native NetworkX 3.7 resource allocation on each full
128-gene/simple-version incidence graph. Model degree is its observed degree
in that full frame, not biological pathway size or a per-query degree. The
reference is published unsigned two-sided GLS P, in the author's native-symbol
upper-triangle orientation. Top N means the top eligible partners **within
this sampled cohort**, not genomewide top N or significance-defined positive
labels. Both signs can be functional; absent or weak association is not a
negative biological label.

All N=1…10 use fractional boundary ties, query-specific expected affinity and
all 128 queries. A common unavailable reference value stays UNKNOWN; an
insufficient query would make the entire fixed-frame N point unscorable.
All 8,128 native P and sign measurements were valid in this capture.

The 42 fixed arms comprise normalized context, historical-supported context,
twenty count-matched source subsets and twenty author-XSwap full-frame degree
controls. Their seeds and budgets were fixed before reference capture. The
project's descriptive rule requires historical O/E to exceed normalized and
all forty controls by more than 1e-12 at **every** N. It is not a significance
test, confidence level, uniform-null assertion or independent replication
count. Binary any-shared-context is a diagnostic and cannot replace RA after
an unfavorable result.

Neither primary RA nor the binary diagnostic exceeded baseline and all fixed
controls at any N. Every N was defined. Historical absolute observed affinity
was lower at all ten N; expected affinity also fell (0.001411 per selected slot
versus normalized 0.010772). The occasional higher historical O/E therefore
does not demonstrate increased absolute evidence, predictive benefit or
scientific accuracy. All individual controls, minima/medians/maxima, absolute
sums, per-query scores, native values and undefined-point rules are preserved.

The native reverse-direction P differences were small (maximum absolute
2.9643e-14), but the predeclared orientation was retained. No direction,
threshold, sample, subgroup or endpoint was chosen from these outcomes.

An independent reviewer rebuilt all 8,128 native P/sign rows directly from the
256 raw column ranges using the standard library, then independently derived
321,216 RA pair scores and all 840 RA/binary curve points and control maxima.
They matched exactly. All per-query availability ledgers and the 102 historical
zero-context queries were checked separately. This verifies implementation and
reporting arithmetic; it does not turn the reference into biological truth.

## Exposure, provenance and interpretation

This is prospective **gene transfer within the same published reference**,
not fresh experimental confirmation. Earlier Broad/RA results informed the
method choice. The earlier 92 full columns contained old–new raw bytes but
not the new–new block used here. Source-only degree/affinity algebra was
inspected during the independent coverage review; a reviewer constructed an
unused inverse-degree dictionary without opening reference outcomes or
changing the design. The claimed pre-value boundary concerns the new reference
block and its readout, not complete source-feature blindness.

Independent metadata/source/control review preceded authorization to capture
the block. All 256 required HTTP ranges were complete (36,114,432 bytes), with
per-range byte hashes and exact server validators. No full-matrix hash is
invented, no request failure is treated as missing biology, and no new fitness
model, covariance fit, FDR reconstruction, GPU or LLM is used.

The published pan-cancer reference and possible source/study reuse remain
limitations. Query pairs, opposite directions, control draws and neighboring
N points are dependent. This single metadata-uniform sample does not settle
whether another population or a separately qualified reference would support
the approach; it does prevent claiming a general transfer benefit from the
earlier exploratory positive result.
