What improved—and what did not

Standard selective duplicate-search feedback primarily increased valid empty outputs: formal valid finals rose from 10/48 to 31/48, while empty finals rose from 3 to 22. Nonempty paper handoffs rose only from 7/48 to 9/48. Rejected duplicates caused zero new source/cache executions and still consumed a model decision within the same four-call budget. Actual total agent calls increased from 117 to 159; this is not an equal-actual-cost claim.

Reference retrieval did not meet the positive-interval criterion. In the follow-up, base and reviewed-skill agents both reached 6.25% Recall@10; skill−base was 0.00 points with a 95% paired interval of −12.50 to +12.50 points. Both final agents underperformed the native 17.26% control on this frame.

How to use the delivered tool

Run the supplied-question CLI in native mode for free PubMed search; Brev/model compute is unnecessary. Optional agent mode uses the existing qualified loopback Nano service with the same bounded tools. It distinguishes final model choices, native candidates already captured and successfully opened exact abstracts.

Missing or empty source metadata does not establish absence of evidence. Discovered papers remain candidate context: Pharos/source reuse and scientific entailment are unassessed without a separate audit.

The installed schema compiler was qualified before testing. Large query string bounds were removed only from native guidance; full controller length/shape/ID/budget validation remained. Selected skills are attributed procedural support, not trusted biological labels.

Limits and sources

Public question/model/tool-development overlap is not independently auditable. Viewed examples were excluded, which does not prove unseen testing. Reference lists are incomplete positive judgments; unmatched papers are not automatically irrelevant or biologically false. Paired 2,000-draw question intervals are conditional/descriptive, not independent-study or whole-graph accuracy claims.
