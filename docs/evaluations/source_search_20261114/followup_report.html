Can a reusable search procedure improve paper retrieval?

Small public retrospective reference-document assessment; not biological truth, model-unseen testing or an official BioASQ submission.

Twenty-four fixed human-authored BioASQ11 questions: twelve factoid and twelve list questions. Both agent arms use the same NVIDIA Nano 8B model, two-search/one-abstract tool budget and four-call cap. Only the short attributed search procedure differs. The direct native query has a smaller tool budget and no model cost.

All fixed forecasts are sealed before selected reference-document values are interpreted. Failed and unavailable cases stay in the denominator. This compares paper retrieval, not whether a paper establishes a scientific claim or adds independent evidence beyond Pharos.

This is the separately frozen recoverable-duplicate follow-up. Only an exact duplicate executed-search request gets an explicit error observation within the same four-call budget. It performs no duplicate source/cache call; all other invalid or model outputs remain terminal. The original fail-fast comparison is retained separately.

Interpretation and reproducibility

  • The public historical dataset may occur in model training; project-new is not model-unseen.
  • Reference document lists are incomplete positive judgments; an unlisted paper is not shown irrelevant or biologically false.
  • Shared live PubMed infrastructure, sources and model create dependence; question bootstrap intervals are conditional/descriptive.
  • All fixed cases, unavailable sources and failed model outputs remain; no post-outcome prompt/model selection.
  • Returning candidate IDs is a retrieval handoff, not a claim that all papers were opened/read or support a biological assertion.

Excluding known viewed publisher examples does not certify unseen evaluation. Complete model-training and native-tool development/tuning membership are not independently audited for these public questions.

The free capability uses the pinned BioMCP 0.9.3 PubMed search plus the existing exact-PMID parser. It does not require paid PaperQA/Edison access. Only PubMed is selected; native ontology suggestions are disabled through the published source-disable option. Source dataset: author BioASQ11 deposit, CC-BY-2.5. No live graph was changed.
