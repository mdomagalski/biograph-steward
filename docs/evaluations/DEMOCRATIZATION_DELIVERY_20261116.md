# Scientist access and final report clarity

BioGraph Steward supports the organizers' democratization goal through a
semi-autonomous question-to-graph workflow. The agent selects a supported source
query, the source tools build a focused graph and cited answer, and the agent
opens selected evidence and proposes review actions. Scientists follow these
steps without writing graph queries.

The protected site makes completed real agent work available for inspection.
An operator installation can execute new supported questions. A separate guided
constructor builds a new Pharos graph from a declared protein list. These are
complementary delivered capabilities with explicit source requirements.

## An easier route to graph construction

**Start here** now includes **Build a graph from your proteins**. Its three steps
explain choosing proteins, selecting evidence, and building/inspecting/exporting.
In an operator installation, its action opens the existing protein-cohort form.
It selects the real retrieval mode and preserves the user's saved workspace.
Opening the form does not make a model or source request.

In shared review, the card clearly identifies the saved demonstration and gives
instructions for local construction. It does not enable live retrieval. The
[three-step guide](../CONSTRUCTION.md#build-through-the-app) explains the same
working route. No new ingestion engine, model prompt or scientific method was
introduced for this improvement.

## A clearer final report

The [four-page report](../../output/docx/BioGraph_Steward_Final_Report.docx) keeps
the requested form layout. It leads with the scientist's workflow, additional
source context and measured gains. It explains CIViC's separate clinical-evidence
role and groups opportunities for further validation in one section. Short
sentences replace semicolons, and unresolved decisions are explained in plain
language.

The methods supplement cites Chervov and colleagues' original
[ProtBoost preprint](https://arxiv.org/abs/2412.04529). The historical function
study adapts published components and the authors' update. Its results remain
separate from the current app's agent workflow and native GO/STRING comparisons.
The [report receipt](democratization_delivery_20261116/final_report.json) records
the source, four-page review and unchanged scientific measurements.

## Validation opportunities

The delivered results support bounded evidence recovery and traceable
investigation. An untouched multi-cohort reference and an independent user study
would extend that evidence. The existing consumed labels cannot establish new
confirmation of whole-graph precision, automatic biological-error pruning or
extra prediction benefit over the fully refreshed baseline. Those questions
remain separate from the delivery improvements completed here.
