# Independent usability feedback

One teammate reported exercising the offline and Pharos-only workflows and
finding that features and exports worked as expected. This is reported user
feedback, rather than an observed, timed task-completion study. The reviewer
had not completed the full saved-source walkthrough when sending these notes.
It provides no biological adjudication or whole-graph accuracy estimate.

The full-reference examples require the complete saved evidence packets. The
hosted reviewer app supplies those packets; reviewers need a browser and the
privately supplied workspace token, rather than their own AWS account. The
standalone software package and a Pharos-only retrieval have smaller source
scope. That difference needs to be explicit in the guide.

| Reported obstacle | Delivery response |
|---|---|
| A lone numbered data-source heading suggests an unfinished sequence. | Remove obsolete numbering from the legacy form; retain the current agent's consistent four-step navigation. |
| Dashed graph lines are hard to select, especially between dashes. | Keep the visual source/review styling and add a wider, continuous transparent pointer target on the existing interactive edge. |
| Navigation labels differ from the corresponding page sections. | Current task tabs already match their sections. Remove remaining legacy numbering that conflicts with them. |
| Build controls appear usable before prerequisite choices are complete. | Gate live construction on the actual exact-term/form state and show the missing prerequisite. Preserve valid defaults and existing request limits. |

Fix qualification is recorded in the software/browser delivery checks. Their presence
does not establish that the reviewer has successfully repeated the tasks after
the update. A follow-up should record where the next action remains unclear,
whether candidate status and source limitations are understood, and whether the
exported answer, retained graph and baseline can be distinguished. Record waiting
time separately from hands-on time. Expert biological judgments are not required
for this interface review.

The [current team guide](../TEAM_REVIEW_GUIDE_20261113.md) and
[reply template](../TEAM_REVIEW_FEEDBACK_20261113.txt) retain the five full-source
tasks for that follow-up. Operator checks, the fixed agent comparison and this
partial external review remain separate evidence.
