# One published annotation-preservation operation: development follow-up

The completed frozen study remains unchanged. It supports a bounded gain over
retained LocalPlus, while stronger current-information controls limit a general
replacement claim. Direct nonexperimental GOA is better for CC and not clearly
beaten for MF. This follow-up is **development on an already consumed
reference**, not an independent confirmation or a new primary endpoint.

The pinned CAFA6 author implementation ends with a simple operation: after
its existing soft passes, append known-term rows with an explicit
**Float32(0.99)** score and group by target/term using MAX. Its competition
known-label input is unsafe for this study and remains excluded. We can test
the same operation using only the complete legal **T0 nonexperimental GOA**
forecast that was already sealed before reference opening. The score is an
uncalibrated ranking heuristic. Nonexperimental source annotations do not
become biological truth through this operation.

Source-only checks identify information absent from the old learned axis:
51 BP, 64 MF and 7 CC positive source memberships across all 3,300 targets. Literal and old-native-alias
counts agree. Their downstream effect has not been isolated. Vocabulary loss,
suppression or calibration of available priors remain possible explanations,
not demonstrated training bugs. The existing full-repertoire BCE follows the authors; no custom loss or
new model fitting is proposed.

The [machine-readable frozen plan](../../tools/contextual_combination/annotation_prior_protocol.json)
permits one operator with fixed source precision across all three aspects and
all18 original cells. It preserves every target and the complete literal head
union. It applies no additional MIN/soft processing after the merge; only the
existing evaluator's canonicalization and fill remain. All original controls
and unfavorable outcomes must be reported. A matched annotation-only0.99
control must reproduce the original binary-prior Fmax peaks or the run stops
for integration review.

There is no new retrieval, GPU inference, training, parameter sweep,
source-family selection or test-driven routing. The original forecasts,
reference files, figures and success gates stay immutable. No graph, pruning
policy or app default changes. Any gain is an exploratory result requiring
a new untouched reference before a confirmatory claim.
