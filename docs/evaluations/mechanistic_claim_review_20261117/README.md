# Expert-curated source-claim assessment

Source review retained 63/64 curator-supported claims and excluded 4/70 unsupported claims.

Retained-reference precision increased in the observed set; the paired uncertainty does not establish an unconditional precision gain.

This publication contains aggregate statistics only. All five prespecified methods, adverse supported-claim exclusions, abstentions and paired pointwise intervals remain visible. Individual cases, identifiers, passages, predictions, private paths and endpoints are omitted.

Supported means at least one original source was accepted under the published coarse curation policy; unsupported means every original source was admitted and reviewed and none accepted. Hypothesis and activity-versus-amount tags count as positive under that historical policy. These are extraction-faithfulness labels, not universally true or false biological relationships.

The corpus and prior grounding endpoint were already used in this project. This new retrospective endpoint is not an unseen independent holdout. Development-only native model fitting and fixed reserve prediction do not establish independent pretraining or new biological replication.

Reference-native retained graphs and full ledgers remain private assessment artifacts. No original Pharos graph, app workspace, source record or review decision is modified.

Reference: [Bachman, Gyori and Sorger (2023)](https://doi.org/10.15252/msb.202211325). [Official dataset](https://doi.org/10.5281/zenodo.7559353), CC BY-NC-SA 4.0. Native INDRA is BSD-2-Clause; this publishing adapter is MIT. The project software license does not relicense source data or article passages.

Uncertainty uses paired whole connected-source-group resampling: 10,000 draws, seed 20261117. Intervals are pointwise, not multiplicity-adjusted simultaneous intervals. Empty retained graphs yield undefined draws, explicitly reported. [Clustered-bootstrap methodology](https://doi.org/10.1111/j.1467-9868.2007.00593.x).

The aggregate JSON records frozen protocol, assessment, prediction-file and scoring-code hashes without distributing individual reference data.
