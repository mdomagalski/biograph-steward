# One pre-cutoff data refit, with stronger source controls

This is a separate **development** comparison on the already consumed
April–November reference. It cannot provide independent confirmation and
changes none of the original forecasts, results or success gates.

Source review verifies a remaining data-update opportunity: the selected
stacker used May 2023 fitting context and historical labels plus the original
CAFA5 `2025_03` additions. The stronger current-only LocalPlus control uses
April 2026 curated seeds. This reflects the frozen historical adaptation;
it is not an undiscovered automatic-refresh failure.

A newer snapshot is not a superset of historical knowledge. The planned
update uses existing positive-union machinery: add only admitted **direct**
April 10, 2026 curator rows for the original 4,040 fitting identities, project
with the same native January 2023 model ontology, and retain every original
full positive. Source-only qualification finds 1,941 additional BP memberships
across 161 fitting proteins; total positives rise 208,835 → 210,776 and native
root-positive fitting rows 3,557 → 3,567. These memberships touch 867 terms;
64 previously had no positive fitting example. They are not 867 new output
heads or independent studies. Missing current records are not judged false.

The single model is the original selected eight-layer, 40-context BP stacker.
Its architecture, seed, batch size, optimizer, loss, 20-epoch budget and pure-GO
postprocessing stay fixed. Fitting context is regenerated from the legal T0
source. Published fit priors are recomputed, and used consistently in both
fitting and final parent-feature caches. The existing final T0 Boolean context
and raw parent forecasts retain their exact bytes.

The author trainer selects SWA states through a validation callback and has
no train-only switch. Its existing callback API can instead receive the fixed
ordering from the original pre-opening checkpoint metadata. The exact original
zero-based epochs **[10, 12, 11]** remain selected; no new validation loader,
score, training-loss choice or epoch search is allowed. Ordinal priorities are
explicitly labeled as priorities, including in the legacy native log. Native
training, loss, optimizer and uniform parameter averaging remain unchanged.

Refitting after settings are fixed is established practice, as illustrated by
[scikit-learn's documented refit operation](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GridSearchCV.html).
That general precedent does **not** validate transferring these exact ProtBoost
SWA positions after this update. This is a disclosed I/O adaptation to the
[published stacker](https://arxiv.org/html/2412.04529v1), with the original
base-model/in-sample calibration limitations retained.

Two fixed controls guard against mistaking information retention for learning:

- Unchanged LocalPlus on the positive union of retained labels, the actual
  augmented fitting targets and complete current-T0 curated graph seeds.
- The original full nonexperimental prior plus retained historical curated
  memberships, scored as binary presence on the complete literal vocabulary.

All six BP setting/view cells, all earlier controls, paired uncertainty and
losses must be reported. Forecasts and source/model choices are sealed before
assessment. No graph, app default, biological review or pruning changes.
The [frozen machine plan](../../tools/contextual_combination/current_refit_protocol.json)
sets the full source, callback, runtime and evaluation contract. GPU execution
is capped at 45 minutes including forecasts, with exact restoration of the
existing Nemotron container on success, timeout or failure. No method-changing
retry is permitted to obtain a better outcome.
