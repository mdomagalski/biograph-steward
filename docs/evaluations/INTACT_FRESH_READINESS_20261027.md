## Existing methods and claim boundary

The scientific representation is reused from IntAct/IMEx and PSI-MI. IMEx
documents sequence-level participants, experimental context, curator checks
and reuse by aggregators such as STRING. It also describes JAMI as an existing
reader/writer implementation. The remaining adapter orchestrates those
capabilities and the project's already implemented assessment flow.
[IMEx resource paper](https://www.nature.com/articles/s41467-020-19942-z).

The official format distinguishes interaction identifiers, contextual fields
and explicit/default negative states; distribution guidance distinguishes
identities from informative cross-references. These support the existing
correction without inventing new biological semantics.
[MITAB 2.7 specification](https://psicquic.github.io/MITAB27Format.html),
[distribution guidance](https://psicquic.github.io/DataDistributionBestPractices.html).

Even a successful fresh result would show preservation of supplied curation on
this finite panel. It would not establish biological truth, independent link
prediction performance, source novelty beyond Pharos or Steward-specific
biological improvement. Those remain separate from this source-fidelity check.
