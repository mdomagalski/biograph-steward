Open the [reviewer site](https://bi-3a117d5e2b3942678dc518fce65ab5d2.ecs.us-east-2.on.aws/)

## Try these five tasks

Try each task before opening the explanation. If stuck for about two minutes,
record where and continue. Waiting for data is separate from difficulty using
the interface. Avoid access tokens in screenshots.

| Task | What to try | What to tell us |
|---|---|---|
| **T1. Find the answer** | In **Start here**, choose **Read the cited answer** (or **Open the real-data example** if offered). Read one result in **Question & graph**. | What question was answered? Was the written answer easy to find? |
| **T2. Explain one connection** | Choose a citation, then **Inspect this source claim**. Read its explanation in **Inspect sources**. | What does the source actually support? Could you find its provider, version and a limitation? |
| **T3. Find an applied change** | Return to **Start here** and choose **Review applied graph qualifications**. Open **What changed** and read the applied-qualification card. | What was excluded, why, and what happens to uncertain records? |
| **T4. Interpret the measured result** | In **What changed**, read the featured protein-location comparison. This compares separate Pharos and native GO source views, separately from the identifier exclusions. | Which source view recovers more labels? Could you find which proteins were assessed and the result's limits? |
| **T5. Understand the handoff** | In the applied-qualification example, use **Export** to download the saved workspace. Read **How the package relates to this workspace**. | Can you distinguish the answer diagram, retained graph, decision ledger and original baseline? |

If a term or result is unclear, use the
[five-minute walkthrough and explanations](JUDGE_WALKTHROUGH.md), and mark the
task **with help**. The two examples show different operations within the same
captured study: added source context and applied qualifications. Their total
record counts are not a before/after comparison with one another.

## Return useful feedback

Use the [short reply template](TEAM_REVIEW_FEEDBACK_20261113.txt), or reply in
plain text. For each task, record **independent / with help / not completed /
not attempted**, time spent, waiting time and the exact obstacle. Then list
your **three most important changes**, marking any blocker. A screenshot and
the selected question are more useful than a general rating.

Also tell us whether anything looked more certain than its evidence justified,
and one research question you would want to try next. Please do not treat a
missing annotation as false biology or a source score as a truth probability.
