BioGraph Steward walkthrough

This tour uses actual application screenshots, edited with synthetic narration. One application supports the question-to-evidence workflow. Saved examples show source integration and graph qualification; benchmark studies assess the approach. The shared website is read-only. Detailed capture and verification provenance accompanies the video.

00:00:00  One workflow, from question to reviewed evidence

BioGraph Steward connects a protein question to an inspectable evidence graph. Open saved work, or create a scoped Pharos workspace locally. Ask a supported question, follow its graph and citations, inspect sources, then save a review as a new run or export. We begin with the Added source context workspace. The shared site replays saved agent work. New live agent questions need a model; form-based readers do not.

Nemotron selects a supported source tool, such as the STRING association reader. It matches the protein to the loaded cohort, checks the attached sources, and validates the query arguments. The agent inspects selected citations and proposes review actions. This recorded investigation shows 8 of 14 matching proteins under its saved limit.

00:02:15  Continue with the same evidence locally

For the demonstration, download the editable KRAS copy, extract it and run its Python launcher. It includes the application, graph and preserved sources. Choose a claim, enter a reviewer, decision and reason, then save a new run. The original is preserved. The shared website stays read-only.

00:02:36  A separate historical prediction study

A separate historical study tests protein function prediction. LocalPlus is a published method that transfers known functions from connected proteins. A learned model combines network, sequence and annotation context. Fmax summarizes the precision-recall balance. Higher is better; this is not percentage accuracy. In the primary evaluation of 1,954 proteins, it rises from 0.055 to 0.073. The sensitivity view rises from 0.172 to 0.210. Paired intervals support both gains over retained LocalPlus within this study. Extra gain beyond refreshed annotations remains uncertain.

00:03:20  The same workflow makes graph decisions inspectable

The second saved example, Qualified Pharos workspace, demonstrates applied graph decisions. It excludes 298 records with obsolete Gene Ontology identifiers and retains 16,687. Every decision preserves its reason and original input, keeping the result inspectable and recoverable.

00:03:44  Examples demonstrate the workflow; studies assess it

These are demonstrations of one workflow, not separate applications. Source integration and applied decisions are illustrated by the two saved workspaces. Location benchmarks and the historical prediction study assess the approach; users do not need benchmark data to explore their own questions.
