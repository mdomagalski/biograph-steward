BioGraph Steward walkthrough

This tour uses actual application screenshots, edited with synthetic narration. It shows saved research data, a recorded agent investigation and local evidence review in a new run. The shared website is read-only. The function-prediction scene presents a separate saved study. Detailed capture and verification provenance accompanies the video.

00:00:00  A protein question, connected to evidence

BioGraph Steward helps scientists ask a protein question, see an evidence graph, and check the sources without writing graph queries. One application provides two saved examples. We begin in the Added source context workspace. The hosted demonstration needs no account or running model.

00:00:20  An inspectable addition to Pharos

Pharos supplies the backbone. Native Gene Ontology location records and sequence-checked STRING associations add traceable context. For KRAS and CDC42BPB, the source passport shows an association absent from captured Pharos. Its provider, original record, identity checks and candidate status remain visible.

00:00:44  Published location labels recovered

A published human-location benchmark matches 31 of the 99 targets, with 51 known location labels. Native annotations recover 44, compared with 41 for captured Pharos. Some observations are shared with the Human Protein Atlas, limiting independent confirmation. OpenCell imaging supplies a separate, previously used research sensitivity check.

00:01:10  The agent follows a supported investigation

Nemotron selects a supported source tool, such as the STRING association reader. It matches the protein to the loaded cohort, checks the attached sources, and validates the query arguments. The agent inspects selected citations and proposes review actions. This recorded investigation shows 8 of 14 matching proteins under its saved limit.

00:01:33  Explore the complete question result

Open the manual reader for all 14 returned partners. Graph view focuses an individual result. Show all results restores the overview. Type a start entity and choose a connected destination. Try KRAS to CDC42BPB, TP53 to nucleus, or BRAF to a pathway. Results and evaluation explains the comparisons.

00:01:57  Continue with the same evidence locally

For the demonstration, download the editable KRAS copy, extract it and run its Python launcher. It includes the application, graph and preserved sources. Choose a claim, enter a reviewer, decision and reason, then save a new run. The original is preserved. The shared website stays read-only.

00:02:18  A separate historical prediction study

A separate historical study tests protein function prediction. LocalPlus is a published method that transfers known functions from connected proteins. A learned model combines network, sequence and annotation context. Fmax summarizes the precision-recall balance. Higher is better; this is not percentage accuracy. In the primary evaluation of 1,954 proteins, it rises from 0.055 to 0.073. The sensitivity view rises from 0.172 to 0.210. Paired intervals support both gains over retained LocalPlus within this study. Extra gain beyond refreshed annotations remains uncertain.

00:03:03  A retained graph with explicit decisions

The Qualified Pharos workspace demonstrates recorded graph decisions. It excludes 298 records with obsolete Gene Ontology identifiers and retains 16,687 records. Every decision preserves its reason and original input, so the retained graph remains inspectable and recoverable.

00:03:26  Understand each result in context

Source additions, location-label recovery, graph qualification and historical prediction answer different questions. The app keeps their evidence and controls visible, so scientists can understand what each result supports and decide what to inspect next.

00:03:44  One application and a clear handoff

Explore the hosted application without signing in. The final handoff contains the report, this demonstration, slides, and one clearly indexed app and graph package. Build a scoped cohort locally, or use a saved example to follow a question all the way to its evidence.
