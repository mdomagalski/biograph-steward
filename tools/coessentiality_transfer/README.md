# Prospective gene transfer within one published reference

This optional research workflow tests an already selected interpretation
method on one fixed sample of previously unevaluated genes. It preserves the
original 92-gene experiments; it neither supplies independent experimental
confirmation nor estimates whole-graph biological accuracy.

The verified gap was integration: the earlier frozen coessentiality workflow
intentionally requires its original learner-derived 92-gene packet. This
adapter uses a genuine ordinary Gold graph and a native historical-model
packet, while reusing existing projection, native-parser, NetworkX, XSwap,
Fortran-range-reader, fractional-tie and query-background functions. It does
not relax or fabricate the earlier packet checks.

The [fixed contract](contract.md) specifies the complete design before new
reference values. In particular:

- Draw 128 genes once, without replacement, from the metadata-only reviewed,
  uniquely mapped 17,231-gene subset. Exclude the earlier 98-gene cohort and
  conflicting gene/product relationships. There are no replacements or
  source-coverage filters.
- Require every selected Pharos identity and pathway response to be complete.
  A genuine complete zero is valid; a transport failure, missing identity,
  inconsistent count or version drift blocks the entire comparison.
- Preserve all 128 genes, including isolates. Compare normalized source
  context with the existing exact-historical-xref feature view, plus twenty
  count and twenty full-frame degree controls. UNKNOWN source encoding is not
  false biology or a production-pruning label.
- Rank native unsigned two-sided GLS P among partners **within the sampled
  128 genes**, using the fixed nonsyntenic mask and N=1…10. Native NetworkX
  resource allocation is primary; binary context is a diagnostic. Report all
  curves, absolute observed/expected affinities, all controls and undefined
  points. No threshold, significance test, model fit or new negative label is
  introduced.

## Run and verify

Use the reviewed local runtime containing NetworkX 3.7 and the pinned author
XSwap backend. Set `PYTHONHASHSEED=2026111301` before Python starts. The CLI
entry points expose required source paths and seals with `--help`:

```sh
python -m tools.coessentiality_transfer.sample --help
python -m tools.coessentiality_feasibility.transfer_source --help
python -m tools.coessentiality_transfer.prepare --help
python -m tools.coessentiality_transfer.matrix --help
python -m tools.coessentiality_transfer.evaluate --help
python -m tools.coessentiality_transfer.report --help
```

The order is metadata/sample freeze → selected-ID source capture → existing
native historical qualification → source/control/statistical freeze →
independent pre-value review → reference capture → evaluation → readable
report. Reference capture is a separate explicit stage, not a side effect of
preparation. It preserves 256 complete native columns (~36 MB), verifies every
HTTP range, server validator and payload hash, and never substitutes a failed
request for biological missingness. It does not claim to hash the full matrix.

`sample.verify`, `prepare.verify` and `matrix.load` replay the declared
identities, source inventories, fixed draw, native history, controls, code
pins and range decoding. Frozen output directories are immutable. A source
or code change requires a new preserved output and an explicit interpretation
of the earlier exposure; rerunning the same comparison is not fresh evidence.

## Sources, licenses and boundaries

The experimental readout follows
[Wainberg et al., 2021](https://doi.org/10.1038/s41588-021-00840-z) and its
[MIT-licensed author code](https://github.com/kundajelab/coessentiality).
Use native [NetworkX resource allocation](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.link_prediction.resource_allocation_index.html)
and the [author XSwap implementation](https://github.com/hetio/xswap), with the
exact versions and bundled licenses recorded by the frozen input receipts.
The published GLS files have no explicit blanket redistribution permission
on their hosting page; raw captures stay outside the public repository.
Their underlying Broad DepMap lineage, the prior selected-method exposure and
possible source/evidence reuse remain disclosed. No Brev, GPU or LLM is needed.

Native source-model membership validates source encoding. A GLS association
rank measures experimental functional concordance. Neither is a calibrated
biological truth label, PPI-binding assay, clinical conclusion or proof of
predictive improvement. Sparse source context and shared-reference transfer
are limitations even if all integrity checks pass.
